# Hassan Sir Classes Website

## Files
- index.html — main website
- style.css — design and responsive layout
- script.js — mobile menu and WhatsApp admission form

## How to run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Double-click `index.html`, or use the VS Code Live Server extension.
4. Replace the `HSC` logo placeholder with the actual logo when available.
